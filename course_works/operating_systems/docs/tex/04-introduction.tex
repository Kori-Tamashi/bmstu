\ssrno{ВВЕДЕНИЕ}

Целью данной курсовой работы является разработка загружаемого модуля ядра Linux, предоставляющего пользовательскому процессу информацию об использовании системой ядер процессора.

Для достижения данной цели необходимо выполнить следующие задачи:
\begin{itemize}
	\item проанализировать известные характеристики использования процессора;
	\item проанализировать известные способы сбора данных об использовании процессора;
	\item спроектировать алгоритмы для достижения поставленной цели;
	\item спроектировать структуру загружаемого модуля;
	\item выбрать наиболее подходящий способ взаимодействия с загружаемым модулем;
	\item выбрать средства реализации загружаемого модуля и реализовать его.
\end{itemize}
