\ssrno{ЗАКЛЮЧЕНИЕ}

В ходе выполнения данной курсовой работы был разработан сервер для отдачи статического содержимого с диска по протоколу HTTP с использованием механизмов prefork и select.

Для достижения поставленной цели необходимо были выполнены следующие задачи:
\begin{itemize}
	\item проведен анализ предметной области;
	\item проведен анализ используемого набора механизмов;
	\item спроектирована архитектуру разрабатываемого сервера;
	\item выбраны средства реализации и реализован сервер;
	\item проведено тестирование разработанного сервера;
	\item проведено исследование разработанного сервера.
\end{itemize}
