\ssrno{РЕФЕРАТ}

Расчетно-пояснительная записка 36 с., 9 рис., 4 лист., 9 ист., 1 прил.

КОМПЬЮТЕРНЫЕ СЕТИ, СТАТИЧЕСКИЙ СЕРВЕР, C4, ПРОТОКОЛ HTTP, PREFORK, SELECT, LINUX, C.

Цель работы: разработка сервера для отдачи статического содержимого с диска по протоколу HTTP с использованием механизмов prefork и select.

В данной работе разрабатывается сервер для отдачи статического содержимого. Проводится анализ предметной области и анализ используемого набора механизмов. Проектируется архитектура в нотации моделирования C4. Проводится реализация на языке программирования C, тестирование сервера и исследуется его работа с использованием программы Apache Benchmark.

В результате работы разработан сервер для отдачи статического содержимого с диска по протоколу HTTP с использованием механизмов prefork и select.  Работоспособность системы протестирована, исследована и подтверждена на реальных сценариях.
