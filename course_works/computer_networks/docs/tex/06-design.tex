\chapter{Конструкторский раздел}

В данном разделе представляются требования к серверу, архитектура сервера, алгоритмы работы сервера, выбор типов и структур данных и классы эквивалентности для тестирования.

\section{Требования к серверу}

Разрабатываемый сервер должен отвечать следующим требованиям:
\begin{enumerate}
	\item поддержка запросов \texttt{GET} и \texttt{HEAD};
	\item поддержка статусов, соответствующих успешному выполнению и ошибкам на стороне клиента;
	\item поддержка передачи файлов до 128 Мбайт;
	\item использование механизма мультиплексирования;
	\item использование логирования.
\end{enumerate}

\section{Выбор типов и структур данных}

В набор выбранных структур данных включены:
\begin{enumerate}
	
	\item Структура \texttt{distributor\_cfg\_t}, определяющая настройки распределителя соединений:
	\begin{itemize}
		\item поле \texttt{listen\_port} определяет порт для прослушивания;
		\item поле \texttt{addr\_info} определяет информацию об адресе.
	\end{itemize}
	
	\item Структура \texttt{distributor\_ctxt\_t}, определяющая контекст распределителя соединений:
	\begin{itemize}
		\item поле \texttt{listen\_sock} определяет сокет прослушивания;
		\item поле \texttt{config} определяет настройки распределителя;
	\end{itemize}
	
	\item Структура \texttt{worker\_info\_t}, содержащая информацию о рабочем процессе:
	\begin{itemize}
		\item поле \texttt{pid} определяет идентификатор процесса;
		\item поле \texttt{to\_worker\_channel} определяет канал связи с процессом;
		\item поле \texttt{logger} определяет систему ведения журнала событий.
	\end{itemize}
	
	\item Структура \texttt{worker\_pool\_t}, определяющая пул рабочих процессов:
	\begin{itemize}
		\item поле \texttt{worker\_count} определяет количество процессов;
		\item поле \texttt{workers} определяет массив информации о процессах.
	\end{itemize}
	
	\item Структура \texttt{conn\_ctxt\_t} определяет контекст обработки подключений:
	\begin{itemize}
		\item поле \texttt{read\_fds} определяет набор файловых дескрипторов для чтения;
		\item поле \texttt{max\_fd} определяет максимальный номер дескриптора;
		\item поле \texttt{conn\_sockets} определяет массив файловых дескрипторов сокетов подключений;
		\item поле \texttt{conn\_sockets\_count} определяет количество подключений.
	\end{itemize}
	
	\newpage
	
	\item Структура \texttt{http\_request\_t}, определяющая HTTP-запрос:
	\begin{itemize}
		\item поле \texttt{method} определяет метод запроса;
		\item поле \texttt{path} определяет путь запроса;
		\item поле \texttt{version} определяет версию протокола;
		\item поле \texttt{body} определяет тело запроса;
		\item поле \texttt{headers} определяет список заголовков.
	\end{itemize}
	
	\item Структура \texttt{http\_response\_t}, определяющая HTTP-ответ:
	\begin{itemize}
		\item поле \texttt{status\_code} определяет код состояния;
		\item поле \texttt{headers} определяет список заголовков;
		\item поле \texttt{body} определяет тело ответа;
		\item поле \texttt{body\_length} определяет длину тела.
	\end{itemize}
\end{enumerate}
