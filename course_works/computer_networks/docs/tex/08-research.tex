\chapter{Исследовательский раздел}

\section{Постановка исследования}

Целью исследования работы сервера является определение следующих значений:
\begin{itemize}
	\item максимальное количество обслуживаемых сервером сетевых соединений;
	\item cкорость отдачи данных по сетевому соединению;
	\item совокупная скорость отдачи данных по всем соединениям.
\end{itemize}

\section{Технические характеристики}

Спецификации устройства, использованного для проведения исследования:
\begin{itemize}
	\item оперативная память 6 ГБ;
	\item процессор Intel(R) Core(TM) i7-9750H с тактовой частотой 2.60ГГц;
	\item 3 физических и 5 логических ядер;
	\item операционная система Linux Ubuntu 22.04.1 LTS 64-разрядная с версией ядра 6.8.0-84-generic.
\end{itemize}

Устройство было нагружено только встроенными приложениями и подключено в сеть электропитания.

Для проведения исследования работы сервера используется однопоточная программа для командной строки Apache Benchmark~\cite{apache-benchmark}. 

\subsection{Максимальное количество обслуживаемых сетевых соединений}

Теоретически максимальное количество обслуживаемых сервером сетевых соединений определяется несколькими характеристиками:
\begin{itemize}
	\item максимальным количеством открытых процессом файловых дескрипторов;
	\item параметром сервера \texttt{MAX\_CONNECTIONS}, определяющим максимальное количество обслуживаемых сетевых соединений рабочим процессом;
	\item параметром сервера \texttt{MAX\_WORKERS}, определяющим максимальное число рабочих процессов.
\end{itemize}

Теоретическое значение максимального количества обслуживаемых сетевых соединений $N_{server\_max\_connections}$ может быть вычислено следующим образом:
\begin{equation}
	N_{server\_max\_connections} = N_{max\_workers}\cdot \min(N_{max\_connections}, N_{open\_files})
\end{equation}
где:
\begin{enumerate}
	\item $N_{max\_workers}$ -- максимальное число рабочих процессов;
	\item $N_{max\_connections}$ -- максимальное количество обслуживаемых сетевых соединений рабочим процессом;
	\item $N_{open\_files}$ -- максимальное количество открытых процессом файловых дескрипторов.
\end{enumerate}
