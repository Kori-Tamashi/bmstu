\ssrno{ВВЕДЕНИЕ}

Целью данной курсовой работы является разработка сервера для отдачи статического содержимого с диска по протоколу HTTP с использованием механизмов prefork и select.

Для достижения поставленной цели необходимо выполнить следующие задачи:
\begin{itemize}
	\item провести анализ предметной области;
	\item провести анализ используемого набора механизмов;
	\item спроектировать архитектуру разрабатываемого сервера;
	\item выбрать средства реализации и реализовать сервер;
	\item провести тестирование разработанного сервера;
	\item провести исследование разработанного сервера.
\end{itemize}
